There are several ways to stay engaged with idrflow while the official brand channels and public community spaces are still being finalized.

## Follow product updates

Use the documentation and [release notes](/release-notes) as the canonical sources for current product behavior and release status.

## Explore the source code

idrflow currently runs on a Langflow-compatible runtime. When you need low-level implementation details, you may still see references to the idrflow repository in source-level documentation.

## Contribute improvements

To contribute changes, follow the repository workflow used by your team or fork, and review [How to contribute](/contributing-how-to-contribute).

## Need help?

For support and enhancement workflows, see [Get help and request enhancements](/contributing-github-issues).
